Drools 规则引擎

2024年7月15日
|编辑此页

概述

Drools 是一个基于 Java 的开源规则引擎，实现了 Rete 算法，用于将业务规则从代码中分离出来。Drools 允许开发人员以声明式的方式定义业务规则，提高系统的灵活性和可维护性。

Drools 核心概念

1. 规则（Rule）

规则是业务逻辑的声明式定义，由条件和动作组成。

rule "规则名称"
    when
        条件（LHS）
    then
        动作（RHS）
end

2. 事实（Fact）

事实是规则引擎处理的数据对象，可以是 Java 对象。

3. 会话（Session）

会话是规则引擎的工作内存，用于存储事实和执行规则。

4. KieBase

KieBase 是规则库的集合，包含所有规则定义。

5. KieSession

KieSession 是 KieBase 的实例，用于执行规则。

<dependency>

2. Drools 配置类

@Configuration
public class DroolsConfig {

    private static final KieServices kieServices = KieServices.Factory.get();
    private static final String RULES_CUSTOMER_RULES_DRL = "rules/order.drl";

    @Bean
    public KieContainer kieContainer() {
        KieFileSystem kieFileSystem = kieServices.newKieFileSystem();
        kieFileSystem.write(ResourceFactory.newClassPathResource(RULES_CUSTOMER_RULES_DRL));

        KieBuilder kieBuilder = kieServices.newKieBuilder(kieFileSystem);
        kieBuilder.buildAll();

        KieModule kieModule = kieBuilder.getKieModule();
        KieContainer kieContainer = kieServices.newKieContainer(kieModule.getReleaseId());

        return kieContainer;
    }
}

规则文件（.drl）

1. 基本结构

package com.guanwx.rules

import com.guanwx.entity.Order

rule "订单金额大于1000折扣"
    when
        $order : Order(amount > 1000)
    then
        $order.setDiscount(0.9);
        System.out.println("订单金额大于1000，打9折");
end

2. 规则元素

package

定义规则所属的包。

package com.guanwx.rules

import

导入 Java 类。

import com.guanwx.entity.Order
import java.util.List

rule

定义规则。

rule "规则名称"
    attributes
    when
        conditions
    then
        actions
end

when（LHS - Left Hand Side）

定义规则的条件部分。

when
    $order : Order(amount > 1000)
    $user : User(age > 18)

then（RHS - Right Hand Side）

定义规则的动作部分。

then
    $order.setDiscount(0.9);
    System.out.println("订单金额大于1000，打9折");
end

规则条件（LHS）

1. 模式匹配

// 简单匹配
Order(amount > 1000)

// 绑定变量
$order : Order(amount > 1000)

// 多个条件
$order : Order(amount > 1000, status == "PENDING")

2. 运算符

运算符说明示例
==等于$order : Order(status == “PAID”)
!=不等于$order : Order(status != “CANCELLED”)
>大于$order : Order(amount > 1000)
>=大于等于$order : Order(amount >= 1000)
<小于$order : Order(amount < 1000)
<=小于等于$order : Order(amount <= 1000)
contains包含$order : Order(items contains “item1”)
not contains不包含$order : Order(items not contains “item1”)
matches正则匹配$order : Order(name matches ”.Test.”)
in在集合中$order : Order(status in (“PAID”, “PENDING”))

3. 逻辑连接符

// and（默认）
$order : Order(amount > 1000, status == "PENDING")

// or
$order : (Order(amount > 1000) or Order(status == "VIP"))

// not
not Order(status == "CANCELLED")

// exists
exists Order(status == "VIP")

4. 条件元素

// eval（评估表达式）
eval($order.getAmount() * 0.9 > 500)

// from（从集合中获取）
$order : Order()
$item : Item() from $order.getItems()

// collect（收集）
List($total : sum.getAmount()) from collect(Order(amount > 1000))

规则动作（RHS）

1. 修改事实

then
    $order.setDiscount(0.9);
    update($order);  // 通知规则引擎事实已更新
end

2. 插入事实

then
    Discount discount = new Discount();
    discount.setRate(0.9);
    insert(discount);  // 插入新事实
end

3. 删除事实

then
    retract($order);  // 删除事实
end

4. 调用方法

then
    System.out.println("订单金额：" + $order.getAmount());
    $orderService.process($order);
end

规则属性

1. 常用属性

rule "规则名称"
    no-loop true  // 防止规则循环触发
    salience 10  // 优先级，数值越大优先级越高
    activation-group "group1"  // 激活组，同一组只有一个规则触发
    when
        $order : Order(amount > 1000)
    then
        $order.setDiscount(0.9);
end

2. 属性说明

属性说明
salience规则优先级，默认为 0
no-loop防止规则循环触发
agenda-group议程组，需要显式激活
activation-group激活组，同一组只有一个规则触发
dialect方言，默认为 java
date-effective规则生效日期
date-expires规则失效日期
lock-on-active锁定激活组

使用示例

1. 定义事实对象

public class Order {
    private String orderId;
    private BigDecimal amount;
    private String status;
    private Double discount;

    // getter、setter
}

2. 定义规则文件

package com.guanwx.rules

import com.guanwx.entity.Order

rule "订单金额大于1000折扣"
    salience 10
    no-loop true
    when
        $order : Order(amount > 1000, status == "PENDING")
    then
        $order.setDiscount(0.9);
        System.out.println("订单金额大于1000，打9折");
        update($order);
end

rule "VIP会员折扣"
    salience 20
    no-loop true
    when
        $order : Order(status == "VIP")
    then
        $order.setDiscount(0.8);
        System.out.println("VIP会员，打8折");
        update($order);
end

3. 执行规则

@Service
public class OrderService {

    @Autowired
    private KieContainer kieContainer;

    public void processOrder(Order order) {
        KieSession kieSession = kieContainer.newKieSession();

        try {
            // 插入事实
            kieSession.insert(order);

            // 执行规则
            kieSession.fireAllRules();

            // 获取结果
            System.out.println("订单折扣：" + order.getDiscount());
        } finally {
            kieSession.dispose();
        }
    }
}

常见面试题

1. Drools 的核心概念？

答：规则、事实、会话、KieBase、KieSession。规则是业务逻辑的声明式定义；事实是规则引擎处理的数据对象；会话是规则引擎的工作内存；KieBase 是规则库的集合；KieSession 是 KieBase 的实例。

2. Drools 规则的结构？

答：规则由 when（条件）和 then（动作）组成。when 部分定义规则触发的条件，then 部分定义规则触发后执行的动作。

3. Drools 的优势？

答：业务规则与代码分离、声明式编程、高性能（Rete 算法）、易于维护、支持复杂业务逻辑。

4. 如何避免规则循环触发？

答：使用 no-loop 属性防止规则循环触发，或者在修改事实后使用 update() 方法通知规则引擎。

5. Drools 的应用场景？

答：业务规则管理、审批流程、风险控制、定价策略、营销活动等需要灵活配置业务规则的场景。

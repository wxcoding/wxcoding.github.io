Java 枚举 Enum

2022年2月18日
|编辑此页

概述

枚举（Enum）是 Java 5 引入的一种特殊类型，用于定义一组固定的常量。枚举使代码更具可读性和类型安全性。

枚举定义

基本语法

public enum ProjectEnum {
    CHINESE,
    MATH,
    ENGLISH
}

枚举特点

  • 枚举是类的特殊形式，继承自 java.lang.Enum
  • 枚举实例是常量，使用 public static final 修饰
  • 枚举构造器默认是 private
  • 枚举不能被继承（所有枚举隐式 final）
  • 枚举可以实现接口

枚举使用

1. 基本使用

public enum ProjectEnum {
    CHINESE,
    MATH,
    ENGLISH
}

public class Main {
    public static void main(String[] args) {
        // 获取所有枚举值
        for (ProjectEnum project : ProjectEnum.values()) {
            printProjectInfo(project);
        }
    }
}

2. 枚举带属性和方法

public enum ProjectEnum {
    CHINESE("语文", "CN"),
    MATH("数学", "MT"),
    ENGLISH("英语", "EN");

    private final String displayName;
    private final String code;

    ProjectEnum(String displayName, String code) {
        this.displayName = displayName;
        this.code = code;
    }

    public String getDisplayName() {
        return displayName;
    }

    public String getCode() {
        return code;
    }
}

3. 使用枚举属性

private static void printProjectInfo(ProjectEnum project) {
    System.out.println("课程：" + project.getDisplayName()
            + "，编码：" + project.getCode());

    switch (project) {
        case CHINESE:
            System.out.println("学习内容：阅读与写作");
            break;
        case MATH:
            System.out.println("学习内容：数字与逻辑");
            break;
        case ENGLISH:
            System.out.println("学习内容：词汇与语法");
            break;
        default:
            System.out.println("暂不支持该课程");
    }
}

枚举常用方法

1. values()

返回所有枚举实例的数组。

ProjectEnum[] values = ProjectEnum.values();
for (ProjectEnum project : values) {
    System.out.println(project);
}

2. valueOf()

根据名称获取枚举实例。

ProjectEnum project = ProjectEnum.valueOf("CHINESE");

3. name()

返回枚举实例的名称。

String name = ProjectEnum.CHINESE.name();  // "CHINESE"

4. ordinal()

返回枚举实例的序号（从 0 开始）。

int ordinal = ProjectEnum.CHINESE.ordinal();  // 0

5. equals()

比较枚举实例。

boolean equals = ProjectEnum.CHINESE.equals(ProjectEnum.valueOf("CHINESE"));  // true

枚举与 Switch

枚举与 switch 语句完美配合，使代码更清晰。

switch (project) {
    case CHINESE:
        System.out.println("语文");
        break;
    case MATH:
        System.out.println("数学");
        break;
    case ENGLISH:
        System.out.println("英语");
        break;
    default:
        System.out.println("其他");
}

枚举实现接口

枚举可以实现接口，为每个枚举实例提供不同的行为。

interface Operation {
    int apply(int a, int b);
}

public enum Calculator implements Operation {
    ADD {
        @Override
        public int apply(int a, int b) {
            return a + b;
        }
    },
    SUBTRACT {
        @Override
        public int apply(int a, int b) {
            return a - b;
        }
    },
    MULTIPLY {
        @Override
        public int apply(int a, int b) {
            return a * b;
        }
    },
    DIVIDE {
        @Override
        public int apply(int a, int b) {
            return a / b;
        }
    };
}

枚举单例模式

枚举是实现单例模式的最佳方式。

public enum Singleton {
    INSTANCE;

    private String value;

    public String getValue() {
        return value;
    }

    public void setValue(String value) {
        this.value = value;
    }
}

// 使用
Singleton singleton = Singleton.INSTANCE;
singleton.setValue("Hello");
System.out.println(singleton.getValue());

枚举单例的优势

  1. 线程安全：JVM 保证枚举实例的线程安全初始化
  2. 序列化安全：枚举天然支持序列化，不会创建新实例
  3. 防止反射攻击：反射无法创建枚举实例
  4. 代码简洁：实现简单，无需额外代码

枚举 vs 常量

使用常量

public class Constants {
    public static final int CHINESE = 1;
    public static final int MATH = 2;
    public static final int ENGLISH = 3;
}

// 使用
int subject = Constants.CHINESE;
if (subject == Constants.CHINESE) {
    // ...
}

使用枚举

public enum Subject {
    CHINESE,
    MATH,
    ENGLISH
}

// 使用
Subject subject = Subject.CHINESE;
if (subject == Subject.CHINESE) {
    // ...
}

对比

特性常量枚举
类型安全弱（int、String）强（自定义类型）
可读性一般好
命名空间可能冲突独立命名空间
可扩展性差好（可添加方法、属性）
Switch 支持支持（int、String）完美支持

枚举高级用法

1. 枚举包含抽象方法

public enum Shape {
    RECTANGLE {
        @Override
        public double area(double width, double height) {
            return width * height;
        }
    },
    CIRCLE {
        @Override
        public double area(double width, double height) {
            return Math.PI * width * width;
        }
    };

    public abstract double area(double width, double height);
}

2. 枚举包含实例方法

public enum Status {
    PENDING("待处理"),
    PROCESSING("处理中"),
    COMPLETED("已完成"),
    FAILED("失败");

    private final String description;

    Status(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }

    public boolean isCompleted() {
        return this == COMPLETED;
    }
}

3. 枚举包含静态方法

public enum Color {
    RED,
    GREEN,
    BLUE;

    public static Color fromString(String color) {
        try {
            return valueOf(color.toUpperCase());
        } catch (IllegalArgumentException e) {
            return null;
        }
    }
}

枚举集合

EnumSet

EnumSet 是专门为枚举设计的 Set 实现，高效且类型安全。

import java.util.EnumSet;

EnumSet<ProjectEnum> set = EnumSet.of(ProjectEnum.CHINESE, ProjectEnum.MATH);
set.add(ProjectEnum.ENGLISH);

// 所有枚举值
EnumSet<ProjectEnum> all = EnumSet.allOf(ProjectEnum.class);

// 范围
EnumSet<ProjectEnum> range = EnumSet.range(ProjectEnum.CHINESE, ProjectEnum.ENGLISH);

EnumMap

EnumMap 是专门为枚举键设计的 Map 实现，高效且类型安全。

import java.util.EnumMap;

EnumMap<ProjectEnum, String> map = new EnumMap<>(ProjectEnum.class);
map.put(ProjectEnum.CHINESE, "语文老师");
map.put(ProjectEnum.MATH, "数学老师");

最佳实践

  1. 使用枚举代替常量：提高类型安全性和可读性
  2. 为枚举添加有意义的名称：使用大写字母和下划线
  3. 枚举实现单例：使用枚举实现单例模式
  4. 使用 EnumSet 和 EnumMap：处理枚举集合时使用专用集合
  5. 避免枚举数量过多：枚举不应该有太多实例（通常少于 100 个）
  6. 提供有意义的 toString()：重写 toString() 方法提供友好的字符串表示

常见面试题

1. 枚举的实现原理？

答：枚举在编译后会被转换为一个继承自 java.lang.Enum 的 final 类，每个枚举实例是该类的 public static final 字段。枚举构造器是 private 的，确保外部无法创建实例。

2. 为什么枚举是实现单例的最佳方式？

答：枚举单例具有以下优势：

  • JVM 保证枚举实例的线程安全初始化
  • 枚举天然支持序列化，不会创建新实例
  • 反射无法创建枚举实例，防止反射攻击
  • 代码简洁，无需额外代码

3. 枚举可以继承吗？

答：枚举不能继承其他类，因为所有枚举隐式继承自 java.lang.Enum。但枚举可以实现接口。

4. 枚举的构造器为什么是 private？

答：枚举的构造器必须是 private，确保枚举实例只能在枚举内部创建，防止外部创建新的枚举实例，保证枚举的不可变性。

5. EnumSet 和 EnumMap 的优势？

答：EnumSet 和 EnumMap 是专门为枚举设计的集合实现，具有以下优势：

  • 类型安全：只能存储指定的枚举类型
  • 高效：内部使用位向量实现，性能优异
  • 内存占用小：因为枚举实例数量有限，可以优化存储

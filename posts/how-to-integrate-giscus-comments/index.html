如何在 AstroPaper 中集成 Giscus 评论

更新于:2025年3月12日
|编辑此页

将轻量级静态博客托管在 GitHub Pages 等平台上有很多优点，但也意味着网站的交互能力有限。好在可以使用 Giscus 在静态网站中嵌入评论功能。

目录

Giscus 的工作方式

Giscus 使用 GitHub API，在关联仓库的 Discussions 中读取和保存 GitHub 用户的评论。

只需在网站中嵌入 Giscus 客户端脚本并配置正确的仓库地址，用户登录 GitHub 后即可查看和发布评论。

这种方案无需服务器：评论存储在 GitHub 上，并由客户端动态加载，因此非常适合 AstroPaper 这样的静态博客。

设置 Giscus

可以在 giscus.app 上轻松完成 Giscus 的设置，下面简要说明相关步骤。

前置条件

要让 Giscus 正常工作，需要满足以下条件：

  • 仓库必须是公开仓库；
  • 已安装 Giscus 应用；
  • 仓库已启用 Discussions 功能。

如果无法满足上述任一条件，就无法集成 Giscus。

配置 Giscus

接下来需要配置 Giscus。大多数情况下，默认选项已经够用；只有在明确了解配置含义并且有特定需求时，才需要修改它们。即使选错也不必担心，之后随时可以调整。

但你仍需要：

  • 为界面选择合适的语言；
  • 指定要关联的 GitHub 仓库，通常是托管 AstroPaper 博客的仓库；
  • 如果不希望他人直接在 GitHub 上随意创建讨论，可创建并指定一个 Announcement 类型的讨论；
  • 设置配色方案。

完成配置后，Giscus 会生成一个 <script> 标签，后续步骤会用到它。

使用简单的 script 标签

此时你应该会得到类似下面的 script 标签：

<script
  src="https://giscus.app/client.js"
  data-repo="[ENTER REPO HERE]"
  data-repo-id="[ENTER REPO ID HERE]"
  data-category="[ENTER CATEGORY NAME HERE]"
  data-category-id="[ENTER CATEGORY ID HERE]"
  data-mapping="pathname"
  data-strict="0"
  data-reactions-enabled="1"
  data-emit-metadata="0"
  data-input-position="bottom"
  data-theme="preferred_color_scheme"
  data-lang="en"
  crossorigin="anonymous"
  async
></script>

将其添加到网站源代码即可。如果你使用 AstroPaper 并希望为文章添加评论，可以打开 PostDetails.astro，将代码粘贴到希望显示评论的位置，例如 Share this post on: 按钮下方。

<Layout {...layoutProps}>
  <main>
    <ShareLinks />

    <script
      src="https://giscus.app/client.js"
      data-repo="[ENTER REPO HERE]"
      data-repo-id="[ENTER REPO ID HERE]"
      data-category="[ENTER CATEGORY NAME HERE]"
      data-category-id="[ENTER CATEGORY ID HERE]"></script>
  </main>
  <Footer />
</Layout>src/layouts/PostDetails.astro

完成！你已经成功在 AstroPaper 中集成评论功能。

支持浅色/深色主题的 React 组件

布局中嵌入的 script 标签是静态的，Giscus 配置（包括 theme）都直接写在布局里。由于 AstroPaper 支持浅色/深色主题切换，如果评论区也能跟随网站主题切换，体验会更好。要实现这一点，需要采用更灵活的方式嵌入 Giscus。

首先安装 Giscus 的 React 组件：

npm i @giscus/react && npx astro add react

然后在 src/components 中创建一个新的 React 组件 Comments.tsx：

import Giscus, { type Theme } from "@giscus/react";
import { GISCUS } from "@/constants";
import { useEffect, useState } from "react";

interface CommentsProps {
  lightTheme?: Theme;
  darkTheme?: Theme;
}

export default function Comments({
  lightTheme = "light",
  darkTheme = "dark",
}: CommentsProps) {
  const [theme, setTheme] = useState(() => {
    const currentTheme = localStorage.getItem("theme");
    const browserTheme = window.matchMedia("(prefers-color-scheme: dark)")
      .matches
      ? "dark"
      : "light";

    return currentTheme || browserTheme;
  });

  useEffect(() => {
    const mediaQuery = window.matchMedia("(prefers-color-scheme: dark)");
    const handleChange = ({ matches }: MediaQueryListEvent) => {
      setTheme(matches ? "dark" : "light");
    };

    mediaQuery.addEventListener("change", handleChange);

    return () => mediaQuery.removeEventListener("change", handleChange);
  }, []);

  useEffect(() => {
    const themeButton = document.querySelector("#theme-btn");
    const handleClick = () => {
      setTheme(prevTheme => (prevTheme === "dark" ? "light" : "dark"));
    };

    themeButton?.addEventListener("click", handleClick);

    return () => themeButton?.removeEventListener("click", handleClick);
  }, []);

  return (
    <div className="mt-8">
      <Giscus theme={theme === "light" ? lightTheme : darkTheme} {...GISCUS} />
    </div>
  );
}src/components/Comments.tsx

这个 React 组件不仅封装了原生的 Giscus 组件，还新增了 lightTheme 和 darkTheme 两个属性。通过两个事件监听器，Giscus 评论区可以与网站主题保持一致，并在网站或浏览器主题变化时动态切换浅色和深色主题。

还需要定义 GISCUS 配置，建议将其放在 constants.ts 中：

import type { GiscusProps } from "@giscus/react";

...

export const GISCUS: GiscusProps = {
  repo: "[ENTER REPO HERE]",
  repoId: "[ENTER REPO ID HERE]",
  category: "[ENTER CATEGORY NAME HERE]",
  categoryId: "[ENTER CATEGORY ID HERE]",
  mapping: "pathname",
  reactionsEnabled: "0",
  emitMetadata: "0",
  inputPosition: "bottom",
  lang: "en",
  loading: "lazy",
};src/constants.ts

请注意，如果在这里指定 theme，它会覆盖 lightTheme 和 darkTheme 属性，导致主题固定不变，效果与前面直接嵌入 <script> 标签的方式相同。

最后，将新的 Comments 组件添加到 PostDetails.astro 中，替换前一步添加的 script 标签：

import Comments from "@/components/Comments";

<ShareLinks />

<Comments client:only="react" />

<hr class="my-6 border-dashed" />

<Footer />src/layouts/PostDetails.astro

这样就完成了。

域名购买流程与选择指南

2026年10月16日
|编辑此页

给个人博客配一个自己的域名，是”正式对外提供服务”的前提——托管平台的默认域名（如 xxx.edgeone.cool）是预览专用、带访问鉴权的，真正面向公众的地址必须是自己绑定的域名。本文记录域名从 0 到买好的完整过程。

先补几个基础知识

域名地址的结构

https://  +  example.com  +  /posts/xxx/
协议          域名             路径

浏览器地址栏通常只显示域名部分，https:// 是自动补的协议头。

裸域与 www 子域

www = World Wide Web，它不是域名的一部分，而是域下的一台”主机名”。早年一台服务器跑多种服务，用主机名区分：www（网站）、mail（邮件）、ftp（文件传输）。如今这个前缀纯属历史习惯保留，但仍有两个实际意义：

  1. Cookie 隔离：裸域上种的 Cookie 会带给所有子域，用 www 承载主站可以规避
  2. DNS 限制：DNS 规范中裸域不能用 CNAME 记录，而 www 子域可以——接入 CDN 时这条经常是关键

主流做法是两个都解析、选一个当主地址、另一个 301 跳转，用户输哪个都能到。

后缀怎么选

核心原则只有一条：看续费价，不看首年促销价。注册商靠首年低价引流，长期持有成本取决于续费。

后缀首年续费/年评价
.cn~29 元~39 元长期持有性价比最高，备案无障碍
.me促销常见 1~9 元~70-80 元语义好（“关于我”），简洁好记
.com~55-69 元~80-90 元认知度最高、最保值，也最贵
.xyz / .top / .icu / .online 等1~9 元60~140 元首年噱头大，续费翻好几倍，观感偏廉价

两个补充判断：

  • 以上后缀均支持个人 ICP 备案，但要打算备案就在国内注册商买（阿里云/腾讯云），备案流程打通最省事
  • 个人博客选 .cn（便宜耐用）或 .me（好看）都是合理答案，.com 是预算充足时的天花板选项

购买流程（阿里云 / 腾讯云通用）

两家的流程几乎同构，以腾讯云为例（阿里云把”域名注册”换成 wanwang.aliyun.com 即可）：

  1. 注册登录：cloud.tencent.com，微信/QQ 扫码最方便
  2. 账号实名：控制台完成个人实名认证
  3. 搜索域名：顶部搜”域名注册”，输入想要的前缀，勾选后缀查询，同时看”新购价”和”续费价”两列
  4. 创建实名模板：结算时选择/新建”实名模板”（个人类型，身份证 + 人脸核验一次，后续购域名可复用）
  5. 支付
  6. 域名实名认证：购买后需提交域名的实名认证（1~3 天审核），未通过实名的域名无法解析——这是管局的强制要求，和账号实名是两回事

阿里云入口：wanwang.aliyun.com → 域名查询 → 结算页选择”域名持有者实名模板” → 支付 → 域名实名认证。

名字怎么起

个人域名的命名思路，按优先级：

  1. 与常用 ID 一致：如果 GitHub 用户名是 yourname，域名也用 yourname.me，简历上”博客 + GitHub”互相印证，一个身份贯穿全网
  2. 避免锁死内容方向的词：个人域名是”关于这个人”的站，博客只是它当前的形态；带 “blog” 字样的域名将来扩展作品集、项目展示页时容易名不副实
  3. 本名拼音：最”耐用”的方案，换技术方向、换 ID 都不过时，前提是接受用真名

买完之后

  • DNS 解析：到域名解析控制台（腾讯云是 DNSPod、阿里云是云解析），按托管平台”域名管理”页面给出的记录类型和值添加 CNAME 记录；TLS 证书由托管平台自动签发
  • 裸域不能用 CNAME 的变通：直接配 A 记录指向平台给出的 IP，或用解析商支持的显性 URL 跳转功能
  • 实名信息与备案人一致：域名持有者实名的身份证信息，务必和将来 ICP 备案的申请人一致，否则备案前要先把域名信息改一致，很折腾
  • 续费提醒：注册商一般支持自动续费，但记得保证支付方式有效——域名过期被抢注的代价远大于年费

和备案的关系

一句话规则：服务器/CDN 节点全在境外，不需要备案；要用中国大陆节点（或全球含大陆区域），域名必须已完成 ICP 备案。备案免费、线上提交、管局审核约 1~2 周，是一次性成本。所以买域名时就该想清楚：如果未来想上国内 CDN 加速，一步到位在国内注册商买、用本人实名，能省去后续迁移的麻烦。

Redis 配置与使用

2023年8月14日
|编辑此页

概述

Redis（Remote Dictionary Server）是一个开源的内存数据结构存储系统，可以用作数据库、缓存和消息中间件。Redis 支持多种数据结构，如字符串、哈希、列表、集合、有序集合等。

Redis 特性

  • 高性能：基于内存存储，读写速度快
  • 丰富的数据结构：支持 String、Hash、List、Set、ZSet 等
  • 原子性操作：所有操作都是原子性的
  • 持久化：支持 RDB 和 AOF 两种持久化方式
  • 主从复制：支持数据复制
  • 高可用：支持哨兵和集群模式

Spring Boot 集成 Redis

1. 添加依赖

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>

2. 配置文件

spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: yourpassword
      database: 0
      timeout: 3000
      lettuce:
        pool:
          max-active: 8
          max-idle: 8
          min-idle: 0
          max-wait: -1ms

3. Redis 配置类

@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
        template.setHashKeySerializer(new StringRedisSerializer());
        template.setHashValueSerializer(new GenericJackson2JsonRedisSerializer());
        template.afterPropertiesSet();
        return template;
    }
}

Redis 数据结构

1. String（字符串）

@Autowired
private RedisTemplate<String, Object> redisTemplate;

// 设置值
redisTemplate.opsForValue().set("key", "value");

// 获取值
String value = (String) redisTemplate.opsForValue().get("key");

// 设置过期时间
redisTemplate.opsForValue().set("key", "value", 60, TimeUnit.SECONDS);

// 设置值，如果不存在
redisTemplate.opsForValue().setIfAbsent("key", "value");

// 递增
redisTemplate.opsForValue().increment("counter");

// 递减
redisTemplate.opsForValue().decrement("counter");

2. Hash（哈希）

// 设置哈希值
redisTemplate.opsForHash().put("user:1", "name", "张三");
redisTemplate.opsForHash().put("user:1", "age", "25");

// 获取哈希值
String name = (String) redisTemplate.opsForHash().get("user:1", "name");

// 获取整个哈希
Map<Object, Object> user = redisTemplate.opsForHash().entries("user:1");

// 删除哈希字段
redisTemplate.opsForHash().delete("user:1", "age");

// 判断哈希字段是否存在
Boolean exists = redisTemplate.opsForHash().hasKey("user:1", "name");

3. List（列表）

// 从左侧添加
redisTemplate.opsForList().leftPush("list", "value1");
redisTemplate.opsForList().leftPush("list", "value2");

// 从右侧添加
redisTemplate.opsForList().rightPush("list", "value3");

// 获取列表范围
List<Object> list = redisTemplate.opsForList().range("list", 0, -1);

// 获取列表长度
Long size = redisTemplate.opsForList().size("list");

// 从左侧弹出
Object value = redisTemplate.opsForList().leftPop("list");

// 从右侧弹出
Object value = redisTemplate.opsForList().rightPop("list");

4. Set（集合）

// 添加元素
redisTemplate.opsForSet().add("set", "value1", "value2", "value3");

// 获取所有元素
Set<Object> set = redisTemplate.opsForSet().members("set");

// 判断元素是否存在
Boolean exists = redisTemplate.opsForSet().isMember("set", "value1");

// 获取集合大小
Long size = redisTemplate.opsForSet().size("set");

// 删除元素
redisTemplate.opsForSet().remove("set", "value1");

// 集合交集
Set<Object> intersection = redisTemplate.opsForSet().intersect("set1", "set2");

// 集合并集
Set<Object> union = redisTemplate.opsForSet().union("set1", "set2");

// 集合差集
Set<Object> difference = redisTemplate.opsForSet().difference("set1", "set2");

5. ZSet（有序集合）

// 添加元素
redisTemplate.opsForZSet().add("zset", "value1", 1.0);
redisTemplate.opsForZSet().add("zset", "value2", 2.0);
redisTemplate.opsForZSet().add("zset", "value3", 3.0);

// 获取范围内的元素
Set<Object> set = redisTemplate.opsForZSet().range("zset", 0, -1);

// 获取元素分数
Double score = redisTemplate.opsForZSet().score("zset", "value1");

// 获取排名
Long rank = redisTemplate.opsForZSet().rank("zset", "value1");

// 删除元素
redisTemplate.opsForZSet().remove("zset", "value1");

// 增加分数
redisTemplate.opsForZSet().incrementScore("zset", "value1", 1.0);

Redisson

1. 添加依赖

<dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson</artifactId>
    <version>3.23.0</version>
</dependency>

2. Redisson 配置

@Configuration
public class RedissonConfig {

    @Value("${spring.data.redis.host}")
    private String host;

    @Value("${spring.data.redis.password}")
    private String password;

    @Value("${spring.data.redis.port}")
    private String port;

    private int timeout = 3000;
    private static String ADDRESS_PREFIX = "redis://";

    @Bean
    RedissonClient redissonSingle() {
        Config config = new Config();

        if (!StringUtils.hasText(host)) {
            throw new RuntimeException("host is empty");
        }
        SingleServerConfig serverConfig = config.useSingleServer()
                .setAddress(ADDRESS_PREFIX + this.host + ":" + port)
                .setTimeout(this.timeout);
        if (StringUtils.hasText(this.password)) {
            serverConfig.setPassword(this.password);
        }
        return Redisson.create(config);
    }
}

3. Redisson 使用

分布式锁

@Autowired
private RedissonClient redissonClient;

public void doSomething() {
    RLock lock = redissonClient.getLock("myLock");
    try {
        // 尝试加锁，最多等待 10 秒，锁自动释放时间 30 秒
        boolean locked = lock.tryLock(10, 30, TimeUnit.SECONDS);
        if (locked) {
            // 执行业务逻辑
        }
    } catch (InterruptedException e) {
        e.printStackTrace();
    } finally {
        if (lock.isHeldByCurrentThread()) {
            lock.unlock();
        }
    }
}

分布式集合

// RMap
RMap<String, Object> map = redissonClient.getMap("myMap");
map.put("key", "value");
Object value = map.get("key");

// RList
RList<Object> list = redissonClient.getList("myList");
list.add("value1");
Object value = list.get(0);

// RSet
RSet<Object> set = redissonClient.getSet("mySet");
set.add("value1");
boolean contains = set.contains("value1");

// RScoredSortedSet
RScoredSortedSet<Object> sortedSet = redissonClient.getScoredSortedSet("mySortedSet");
sortedSet.add(1.0, "value1");
sortedSet.addScore("value1", 0.5);

Redis 持久化

1. RDB（Redis Database）

RDB 是 Redis 默认的持久化方式，通过定时保存数据快照实现。

配置

save 900 1     # 900 秒内至少 1 个 key 变化则保存
save 300 10    # 300 秒内至少 10 个 key 变化则保存
save 60 10000  # 60 秒内至少 10000 个 key 变化则保存

rdbcompression yes    # 压缩 RDB 文件
rdbfilename dump.rdb   # RDB 文件名
dir /var/lib/redis     # RDB 文件目录

优缺点

  • 优点：文件小，恢复速度快，适合备份
  • 缺点：可能丢失最后一次持久化后的数据

2. AOF（Append Only File）

AOF 通过记录所有写操作命令实现持久化。

配置

appendonly yes          # 启用 AOF
appendfilename "appendonly.aof"  # AOF 文件名
appendfsync everysec    # 每秒同步一次
no-appendfsync-on-rewrite no   # 重写时不同步
auto-aof-rewrite-percentage 100  # AOF 文件大小增长 100% 时重写
auto-aof-rewrite-min-size 64mb  # AOF 文件最小重写大小

优缺点

  • 优点：数据安全性高，丢失数据少
  • 缺点：文件大，恢复速度慢

Redis 常用命令

1. 字符串命令

SET key value          # 设置值
GET key                # 获取值
SETNX key value        # 设置值，如果不存在
SETEX key seconds value  # 设置值并设置过期时间
INCR key               # 递增
DECR key               # 递减

2. 哈希命令

HSET key field value   # 设置哈希字段
HGET key field         # 获取哈希字段
HGETALL key            # 获取所有哈希字段
HDEL key field         # 删除哈希字段
HEXISTS key field      # 判断哈希字段是否存在

3. 列表命令

LPUSH key value        # 从左侧添加
RPUSH key value        # 从右侧添加
LPOP key               # 从左侧弹出
RPOP key               # 从右侧弹出
LRANGE key start stop  # 获取列表范围
LLEN key               # 获取列表长度

4. 集合命令

SADD key member        # 添加元素
SREM key member        # 删除元素
SMEMBERS key           # 获取所有元素
SISMEMBER key member   # 判断元素是否存在
SCARD key              # 获取集合大小

5. 有序集合命令

ZADD key score member  # 添加元素
ZREM key member        # 删除元素
ZRANGE key start stop # 获取范围内的元素
ZSCORE key member      # 获取元素分数
ZRANK key member       # 获取元素排名

最佳实践

  1. 合理使用数据结构：根据场景选择合适的数据结构
  2. 设置过期时间：避免内存泄漏
  3. 使用连接池：提高性能
  4. 监控 Redis：定期检查 Redis 状态
  5. 持久化配置：根据需求选择合适的持久化方式
  6. 避免大 Key：大 Key 会影响性能

常见面试题

1. Redis 的数据结构有哪些？

答：String、Hash、List、Set、ZSet（有序集合）、Bitmap、HyperLogLog、Geo。

2. Redis 的持久化方式有哪些？

答：RDB（快照持久化）和 AOF（日志持久化）。RDB 文件小，恢复快，但可能丢失数据；AOF 数据安全性高，但文件大，恢复慢。

3. Redis 为什么快？

答：基于内存存储、单线程模型、IO 多路复用、高效的数据结构。

4. Redis 的过期策略？

答：定期删除（主动删除）和惰性删除（被动删除）。定期删除定期扫描过期 key；惰性删除访问时检查是否过期。

5. Redisson 的优势？

答：Redisson 是 Redis 的 Java 客户端，提供了丰富的分布式对象，如分布式锁、分布式集合、分布式 Map 等，简化了分布式编程。
